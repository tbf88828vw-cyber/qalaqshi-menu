# Qalaqshi — видео-меню с админ-панелью

Сайт-меню ресторана: видео-карусели по категориям, спецпредложения сверху, отдельный бар, три языка (GE / EN / RU), тёмная и светлая тема, админ-панель с телефона.

```
/            — сайт для гостей
/admin       — админ-панель
```

## Как это устроено

| Часть | Что делает |
|---|---|
| `public/` | Сайт: `assets/app.js` + `app.css` (без фреймворков, ~15 КБ в сжатом виде), текстура бара, админка |
| `api/page.js` | Отдаёт главную страницу, меню уже встроено в HTML: ноль лишних запросов. Кэшируется на CDN Vercel |
| `api/admin.js` | API админки: вход, сохранение, история, загрузка файлов |
| `lib/` | Логика меню, хранилище, авторизация |
| `lib/seed-data.js` | Исходное меню из Poster (347 позиций, цены сверены). Используется, пока в базе ничего не сохранено |

Меню хранится в **Upstash Redis**, видео и фото лежат в **Vercel Blob**. Оба сервиса подключаются в Vercel парой кликов, npm-пакеты не нужны.

### Почему сайт быстрый даже на слабом интернете
- Страница с меню отдаётся с CDN мгновенно. После изменений в админке она обновляется в фоне за ~10–20 секунд.
- Видео сжимаются **в браузере администратора** при загрузке: обрезка под 9:16, H.264, 30 кадров/с, без звука, до 15 секунд, в трёх версиях: 1080p (~5 Мбит/с), 720p (~2,8 Мбит/с) и 480p (~1,1 Мбит/с). Плюс обложка и размытое превью на ~300 байт. Видео с iPhone (HEVC, HDR, .mov) автоматически переводятся в H.264 — он играет на любых телефонах и браузерах, включая Android.
- Сайт сам находит, где на кадре блюдо («точка на превью»): по ней кадрируется карточка и окно блюда, оттуда же идёт пар. Точку можно поправить вручную — нажать на превью в админке.
- Сразу видно размытое превью, затем обложка, затем видео, которое плавно проявляется.
- Играет только активная карточка в видимой карусели. Соседние подгружаются заранее, далёкие выгружаются из памяти. Поэтому телефон не греется и не тормозит.
- Качество выбирается по экрану и реальной скорости сети: на хорошем интернете — 1080p, на слабом — 720p/480p. Если видео подвисает дольше 3,5 с, сайт на лету переходит на ступень ниже, а когда сеть восстанавливается — обратно.
- В режиме экономии трафика и при «уменьшении движения» видео не запускаются сами, остаются обложки.

## Деплой на Vercel (один раз)

1. **Код.** Замените содержимое вашего репозитория `qalaqshi-landing-main` этими файлами и сделайте push. Или создайте новый репозиторий и импортируйте его в Vercel (**Add New → Project**).
   Framework Preset: **Other**. Build Command и Output Directory оставьте пустыми, они заданы в `vercel.json`.
2. **База данных.** В проекте Vercel откройте **Storage → Create Database → Upstash for Redis** (бесплатный план) и привяжите её к проекту. Переменные `KV_REST_API_URL` и `KV_REST_API_TOKEN` добавятся сами.
3. **Хранилище файлов.** **Storage → Create → Blob**, привяжите к проекту. Переменная `BLOB_READ_WRITE_TOKEN` добавится сама.
4. **Пароли.** **Settings → Environment Variables**:
   - `ADMIN_PASSWORD`: пароль владельца/администратора, полный доступ.
   - `STAFF_PASSWORD` *(необязательно)*: пароль для официантов и хостес. С ним видна только вкладка «Стоп-лист», цены и блюда менять нельзя.
5. **Deployments → … → Redeploy**, чтобы новые переменные применились.
6. Домен: **Settings → Domains**.

### Свой домен на GoDaddy
Хостинг оставляйте на Vercel (там CDN, база и файлы), а домен на GoDaddy просто «направьте» на Vercel:
1. Vercel → **Settings → Domains → Add** → впишите `вашдомен.ge` и `www.вашдомен.ge`.
2. GoDaddy → **My Products → Domain → DNS** → запись **A** для `@` со значением `76.76.21.21` и **CNAME** для `www` со значением `cname.vercel-dns.com` (старые A/CNAME для `@` и `www` удалите).
3. Через 10–60 минут Vercel сам выпустит HTTPS-сертификат. Точные значения Vercel показывает на той же странице Domains — если они отличаются, берите их.

> Тариф Hobby в Vercel только для некоммерческого использования. Для сайта ресторана нужен **Pro**. Лимиты трафика Blob зависят от тарифа, их видно в Vercel → Usage.

## Как работать в админке

Откройте `https://ваш-домен/admin` и войдите по паролю. На iPhone удобно «Поделиться → На экран Домой»: админка откроется как приложение.

- **Стоп-лист.** Выключатель у каждой позиции. При выключении можно выбрать:
  - «До утра»: позиция сама вернётся в 06:00 по Тбилиси;
  - «Пока не верну вручную»;
  - «До даты и времени».
- **Меню.** Категории кухни и бара, их порядок (стрелки ↑↓). Для каждой категории:
  - куда попадают блюда в режиме «Авто»: «С видео — в карусель» или «Все — в ленту»;
  - кнопки «Все — в карусель / Все — в ленту / Всем „Авто“»;
  - выключатель **«Показывать компактную ленту»**: если выключить, лента исчезает вместе с позициями, без пустого места.

  У каждого блюда есть выбор **«Где показывать на сайте»**: Авто / Большая карусель / Компактная лента.

  Внутри категории можно добавлять, редактировать и удалять блюда: видео или фото, названия и описания на 3 языках, состав, цена, старая цена (для скидки), порция, метки («Хит», «Острое», …), эффект пара.
- **Спец.** Спецпредложения автоматически показываются первой каруселью. Можно задать надпись на ленточке, даты «с/по» и дни недели. Кнопка «Из блюда меню» заполняет форму за вас.
- **Настройки.**
  - Заголовок и описание главного экрана, слоган, контакты, WhatsApp для брони, фон главного экрана.
  - **Шрифты и размер текста**: шрифт заголовков и текста, размер текста, заголовков и логотипа, с живым превью. Сайт подстраивает размеры под экран сам, грузинский текст всегда набирается Noto Georgian.
  - Режим стопа: скрывать позиции или показывать серыми.
  - **История изменений**: любое действие можно отменить.
  - Резервная копия в файл.
  - Перенос старых фото из Poster на ваш сервер.
  - Очистка неиспользуемых файлов.

**Видео можно загружать прямо с iPhone** (Safari) или из Chrome на компьютере. Снимайте вертикально, 5–10 секунд, при хорошем свете. Любой формат iPhone (HEVC, HDR, .mov) переводится в универсальный MP4 автоматически. Сжатие идёт на устройстве администратора — не закрывайте вкладку, пока не появится «Готово».

Гости могут переключать тему (солнце/луна в шапке); выбор запоминается.

## Локальный запуск

```bash
npm run dev        # http://localhost:3000, админка: /admin, пароль: qalaqshi
```
Без подключённых хранилищ всё сохраняется в папку `.data/` и `public/uploads/`.

## Бар
Фон бара — гладкая текстура (`public/assets/bar/stone.webp`, 3 КБ), логотип-водяной знак только вверху. Иконки разделов — тонкие линейные рисунки в стиле логотипа, встроены в код. Свою картинку для раздела можно поставить: **Меню → Бар → «Раздел» → Своя иллюстрация**.

## Безопасность
Если пароль или токен когда-либо попадали в переписку или скриншоты — смените `ADMIN_PASSWORD` в Vercel, а в **Storage → Blob → Settings** нажмите **Revoke/Rotate Token**, затем Redeploy.
