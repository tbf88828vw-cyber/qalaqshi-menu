# Qalaqshi — видео-меню с админ-панелью

Сайт-меню ресторана: видео-карусели по категориям, спецпредложения сверху, отдельный бар с иллюстрациями, три языка (GE / EN / RU), админ-панель с телефона.

```
/            — сайт для гостей
/admin       — админ-панель
```

## Как это устроено

| Часть | Что делает |
|---|---|
| `public/` | Сайт: `assets/app.js` + `app.css` (без фреймворков, ~15 КБ в сжатом виде), иллюстрации бара, админка |
| `api/page.js` | Отдаёт главную страницу, меню уже встроено в HTML: ноль лишних запросов. Кэшируется на CDN Vercel |
| `api/admin.js` | API админки: вход, сохранение, история, загрузка файлов |
| `lib/` | Логика меню, хранилище, авторизация |
| `lib/seed-data.js` | Исходное меню из Poster (347 позиций, цены сверены). Используется, пока в базе ничего не сохранено |

Меню хранится в **Upstash Redis**, видео и фото лежат в **Vercel Blob**. Оба сервиса подключаются в Vercel парой кликов, npm-пакеты не нужны.

### Почему сайт быстрый даже на слабом интернете
- Страница с меню отдаётся с CDN мгновенно. После изменений в админке она обновляется в фоне за ~10–20 секунд.
- Видео сжимаются **в браузере администратора** при загрузке: обрезка под 9:16, H.264, 30 кадров/с, без звука, до 15 секунд, в двух версиях: 720p (~2 Мбит/с) и 480p (~0,85 Мбит/с). Плюс обложка и размытое превью на ~300 байт.
- Сразу видно размытое превью, затем обложка, затем видео, которое плавно проявляется.
- Играет только активная карточка в видимой карусели. Соседние подгружаются заранее, далёкие выгружаются из памяти. Поэтому телефон не греется и не тормозит.
- Качество выбирается по скорости сети. Если видео начинает «подвисать», сайт на лету переключается на лёгкую версию.
- В режиме экономии трафика и при «уменьшении движения» видео не запускаются сами, остаются обложки.

## Деплой на Vercel (один раз)

1. **Код.** Замените содержимое вашего репозитория `qalaqshi-landing-main` этими файлами и сделайте push. Или создайте новый репозиторий и импортируйте его в Vercel (**Add New → Project**).
   Framework Preset: **Other**. Build Command и Output Directory оставьте пустыми, они заданы в `vercel.json`.
2. **База данных.** В проекте Vercel откройте **Storage → Create Database → Upstash for Redis** (бесплатный план) и привяжите её к проекту. Переменные `KV_REST_API_URL` и `KV_REST_API_TOKEN` добавятся сами.
3. **Хранилище файлов.** **Storage → Create → Blob**, привяжите к проекту. Переменная `BLOB_READ_WRITE_TOKEN` добавится сама.
4. **Пароли.** **Settings → Environment Variables**:
   - `ADMIN_PASSWORD`: пароль владельца/администратора, полный доступ.
   - `STAFF_PASSWORD` *(необязательно)*: пароль для официантов и хостес. С ним видна только вкладка «Стоп-лист», цены и блюда менять нельзя.
5. **Deployments → … → Redeploy**, чтобы новые переменные применились.
6. Домен: **Settings → Domains**.

> Тариф Hobby в Vercel только для некоммерческого использования. Для сайта ресторана нужен **Pro**. Лимиты трафика Blob зависят от тарифа, их видно в Vercel → Usage.

## Как работать в админке

Откройте `https://ваш-домен/admin` и войдите по паролю. На iPhone удобно «Поделиться → На экран Домой»: админка откроется как приложение.

- **Стоп-лист.** Выключатель у каждой позиции. При выключении можно выбрать:
  - «До утра»: позиция сама вернётся в 06:00 по Тбилиси;
  - «Пока не верну вручную»;
  - «До даты и времени».
- **Меню.** Категории кухни и бара, их порядок (стрелки ↑↓) и способ показа:
  - «Видео-карусель»;
  - «Компактная лента»: для соусов, гарниров, хлеба.

  Внутри категории можно добавлять, редактировать и удалять блюда: видео или фото, названия и описания на 3 языках, состав, цена, старая цена (для скидки), порция, метки («Хит», «Острое», …), эффект пара.
- **Спец.** Спецпредложения автоматически показываются первой каруселью. Можно задать надпись на ленточке, даты «с/по» и дни недели. Кнопка «Из блюда меню» заполняет форму за вас.
- **Настройки.**
  - Тексты главного экрана, контакты, WhatsApp для брони, фон главного экрана.
  - Режим стопа: скрывать позиции или показывать серыми.
  - **История изменений**: любое действие можно отменить.
  - Резервная копия в файл.
  - Перенос старых фото из Poster на ваш сервер.
  - Очистка неиспользуемых файлов.

**Видео лучше загружать из Safari (iPhone/Mac) или Chrome.** Снимайте вертикально, 5–10 секунд. Если iPhone снимает в HEVC и Chrome на Windows не может его прочитать, откройте админку в Safari или включите «Настройки → Камера → Форматы → Наиболее совместимый».

## Локальный запуск

```bash
npm run dev        # http://localhost:3000, админка: /admin, пароль: qalaqshi
```
Без подключённых хранилищ всё сохраняется в папку `.data/` и `public/uploads/`.

## Иллюстрации бара
- `public/assets/bar/wine.webp`, `grapes.webp`: ваши иллюстрации.
- Остальные (чача, коньяк, водка, виски, пиво, коктейли, кофе, лимонады) нарисованы в похожем стиле скриптом `scripts/art/make_art.py`.

Любую иллюстрацию можно заменить: **Меню → Бар → «Раздел» → Своя иллюстрация**.
